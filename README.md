# KiaxeKuKristu – Juntos por Cristo | Site completo (frontend)

Este pacote contém uma versão ampliada do site institucional, construída com base no conteúdo fornecido no dossier da organização.

## Incluído
- Página institucional responsiva.
- Missão, visão, princípios e valores.
- 4 programas: Mãos que Servem; Gerados por Deus; Essência & Propósito; Corações em Chama.
- Área dedicada ao Futuro em Jogo – Academia Social e Desportiva.
- Atividades e plano 2026–2027.
- Indicadores e monitorização.
- Parcerias.
- Voluntariado.
- Interesse/inscrição no Futuro em Jogo.
- Governação e responsáveis.
- Contactos.
- Formulários demonstrativos.

## Importante
Esta é uma implementação frontend completa para apresentação/protótipo. Os formulários ainda não enviam dados para uma base de dados e não existe autenticação real, painel administrativo, pagamentos ou gestão segura de menores.

Para transformar em sistema de produção, o próximo passo é ligar o frontend a um backend/API e base de dados, implementar autenticação, permissões, proteção de dados, gestão de conteúdos, notificações e alojamento.

## Como abrir
Abra `index.html` num navegador. Não é necessário servidor para a demonstração.
